# Security Policy

## Supported versions

Security fixes are generally made on the latest released version of each platform:

| Platform | Supported version |
| --- | --- |
| Android | Latest release |
| iOS | Latest release |

Upgrade to the latest release before reporting an issue when possible.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions, or pull requests.
Use [GitHub's private vulnerability reporting for this repository](https://github.com/albertolicea00/LlamaCon99/security/advisories/new).
If private reporting is unavailable, contact the maintainers privately through the
[project owner's GitHub profile](https://github.com/albertolicea00).

Include as much of the following as you safely can:

- A description of the issue and its potential impact.
- Affected platform, app version, OS version, and device model.
- Reproduction steps or a proof of concept that does not expose real user data.
- Any suggested mitigation or fix.

Please give maintainers a reasonable opportunity to investigate and prepare a fix before publicly
disclosing the issue. Do not include real contacts, phone numbers, credentials, signing material,
or other people's private data in a report.

## Scope

This policy covers the LlamaCon99 Android and iOS applications and their repository configuration.
Third-party services and operating-system components should be reported to their respective
maintainers unless the issue is caused by LlamaCon99's integration with them.
